# LeetCode-problems

A collection of LeetCode problem solutions, primarily in Rust with some C++.

Each file is named after the corresponding problem. To find the problem description, replace `$NAME_FILE$` with the filename (without extension):

```
https://leetcode.com/problems/$NAME_FILE$/description/
```
